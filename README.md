# TCP-Client-Server-Pokemon-Bank
Application protocol service functionality is to act as a bank that holds client's Pokémon (Pocket Monsters) and information. 
TCP Server + Client


Server and Client Session Establishment done through simplified Challange Authentication Protocol

Entry Consists of 

I. Pokémon Name
II. Type
III. Health Points (HP)
IV. Level
V. Move 1
VI. Move 2
VII. Move 3
VIII. Move 4

Transactions between Client and Bank:

I. LOCATE
II. SEARCH
III. STORE
IV. WITHDRAW
